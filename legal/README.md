# Legal templates

Reusable engagement paperwork for Cindrasec. These are **blank templates** — no client data.
Current: **RoE version 3.0** — a single ~2-page document combining the authorization and the
rules of engagement (the authorization is signed as §5 of the same page, so there is no separate
letter to chase).

| File | Use |
|---|---|
| `Rules-of-Engagement.md` | Canonical, version-controlled source. Edit this; it's the source of truth. |
| `Cindrasec_RoE_Authorization.docx` | Client-facing copy to fill, sign, and send. Keep it in sync with the `.md`, and bump the RoE version number in both when the terms change. |

## How to use per engagement

1. Copy the DOCX, fill the §1 fields and the §2 scope table (have the client **initial each
   in-scope asset** — that's per-asset proof of authorization).
2. Both parties sign §5 **before any scanning starts** — no signature, no scan.
3. Keep the signed copy with the engagement record (not in this repo).

## Before going further

- Fine for **free pilots** as-is.
- Get a **lawyer review before the first paid engagement**, and always for international clients.
- These templates are not legal advice.
